- 한 줄: 최근 N일 가격대별 거래량(볼륨 프로파일)의 가치 구간(거래량 70%, VAH·VAL·POC)을 계산해, 가격이 가치 구간 **밖에서 받아들여졌을 때(수용)**만 추세 진입을 허용하고, 다시 안으로 들어오면(거부·실패한 경매) 돌파 실패로 본다.

## 글에서 가져온 것 / 버린 것 (에이전트 판단)
| 구분 | 내용 |
|---|---|
| 표준 개념(가져옴) | 옥션 마켓 이론(Steidlmayer·Dalton): 가치 구간 = 거래량 70%가 쌓인 가격대, POC = 거래량 최대 가격, 가치 구간 안 = 균형, 밖 = 불균형. 돌파가 가치 구간 밖에서 **수용**되는지·**거부**되는지 구분 |
| 검증 안 된 수치(가설로만) | "시장은 시간의 70%가 균형" — 가치 구간의 정의(거래량 70%)와 시간 비율을 섞은 주장, 근거 없음. "80% 규칙"(가치 구간 밖에서 열고 다시 들어와 버티면 반대편까지 갈 확률 80%) — 업계 경험칙, 출처의 실증 없음 |
| 오류 | FVG(Fair Value Gap — 캔들 3개 사이 빈 가격, ICT 용어)를 옥션 이론의 Fair Value(가치 구간)와 같은 것처럼 설명 — 서로 다른 개념 |
| 지금 못 하는 것 | 장중 세션 프로파일 셋업·호가 반응 진입·빅트레이드(체결 단위 자료 필요), 숏(현물만), 선물 4계약 운용 — 운영은 M2 하루 1회 판정만 지원(주기 판정 생기면 재검토) |
| 주관 표현(그대로는 규칙 불가) | "강하게 벗어난다", "애매하면 관망", 프로파일 모양(D·P·b·Thin) — 수치 정의가 있어야 시험 가능 |

## 왜 수익이 나야 하는가 (한 문단)
btc-trend v1은 승률 39%로 돌파 실패(되돌림) 손실이 잦다. 옥션 이론의 주장대로 "가치 구간 안으로 다시 들어오는 돌파 = 실패한 경매"라면, 돌파 직후 가격이 이전 가치 구간 위에 **머무는지**(수용)로 가짜 돌파를 일부 거를 수 있다. 반대로 BTC 일봉 25일 종가 돌파는 거의 항상 이미 가치 구간 위라서 필터가 아무것도 안 바꿀 수도 있고(결과 동일 → 시험 안 된 것), 진입이 늦어져 큰 추세의 앞부분을 놓칠 수 있다(이번 탐색에서 국면·확인 필터는 대부분 효과 작음/악화).

## 데이터 · 능력
- BTC 1분봉(운영 수집 사본에 거래량·**테이커 매수 거래량(taker_buy_base)** 있음) → 일별·N일 가격대별 거래량 계산 가능, 테이커 매수−매도로 CVD(누적 거래량 델타) 근사도 가능. 한국 주식은 일봉뿐(분봉은 CP-032 뒤).
- 판정은 지금처럼 하루 1회(UTC 00:15) — 전일까지 확정된 1분봉으로 계산하면 룩어헤드 없음.

## 시험 순서 (R2 사전 등록 전 초안)
1. **사건 연구(기준선 병기)**: 일봉 종가가 직전 N일(20·50) 가치 구간 위/안/아래일 때 다음 5·20일 수익 분포 vs 모든 날 기준선. 가치 구간 위 마감 뒤 다음 날 다시 안으로 들어온(거부) 경우 vs 머문(수용) 경우 비교.
2. 사건 연구에서 차이가 기준선과 구별될 때만: v1 + 수용 필터(돌파일 종가 > 직전 N일 VAH, 다음 판정에서도 VAH 위면 진입) 1개를 v1과 대조(24개 일봉 경계 중앙값, 학습 2017-09~2021 / 확인 2022~2025).
- 다중 비교 주의: BTC에서 이미 약 440설정을 탐색함 → 이 카드는 설정 2~4개 안에서 끝낸다.
