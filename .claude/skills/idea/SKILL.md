# /idea — 아이디어 카드 만들기 (R0)

입력: `$ARGUMENTS` (아이디어 한 줄. 비어 있으면 사용자에게 한 줄을 묻는다 — 질문은 1개).

## 절차
1. `ideas/` 기존 카드를 `Glob`으로 훑어 **같은 아이디어가 이미 있는지**(특히 "폐기" 표시) 확인한다. 있으면 그 카드 경로와 폐기 이유를 보여 주고 새 카드를 만들지 묻는다.
2. 아래 양식으로 `ideas/<YYYY-MM-DD>-<짧은_이름>.md`를 만든다. 날짜는 사용자 메시지·시스템 정보의 오늘 날짜를 쓴다(현재 시각 추정 금지).
3. 능력 판정은 CLAUDE.md §0 기준: 일봉·09:30 1회 판정·시장가·보유 3·일 5건·1회 100만 원 안이면 "지금 가능", 분봉·지정가·장중 손절·실시간·동적 유니버스·다종목 20 등은 "CP-032 뒤"로 분류하고 **구현하지 않는다**.
4. 끝나면 카드 경로와 "다음 행동" 한 줄만 답한다(규칙화로 넘기려면 `spec-writer` 에이전트, 또는 사용자가 `/new-candidate <이름>`).

## 카드 양식
```markdown
# <아이디어 이름>

- 날짜: <YYYY-MM-DD> · 상태: 카드 (카드 → 규칙화 → 선별 중 → 폐기 | 보류 | 인계)
- 한 줄: <사용자 입력 그대로>

## 왜 수익이 나야 하는가 (한 문단)
<행동적·구조적 근거. "과거에 잘 됐다"는 근거가 아니다. 모르면 "근거 없음 — 데이터 마이닝 위험"이라고 적는다>

## 언제 사고 언제 파는가 (말로, 전일 확정 일봉 기준)
- 진입:
- 청산:
- 손절(크기 계산용):

## 필요 능력 · 데이터
- 판정: 일봉 / 09:30 1회 → 지금 가능 | CP-032 뒤 (이유)
- 주문: 시장가 → 지금 가능 | 지정가·정정 필요 → CP-032 뒤
- 유니버스: 30종목 고정(U-A) | 동적·다종목 → CP-032 뒤

## 실패할 것 같은 시장 국면
| 국면 | 판별 지표 | 예상 실패 양상 |
|---|---|---|

## 폐기 기준 초안 (R2에서 확정, 실행 뒤 변경 금지)
- 1차 선별(창 4·7 합산): 거래당 기대값 ≤ 0 또는 거래 < 10건 → 폐기
- 시도 상한: 버전당 5회

## 한계
생존편향 포함(사후 선택 30종목) — 모든 수익은 과대 추정. 비용 가정·호가 표·장중 손절 없음.
```
