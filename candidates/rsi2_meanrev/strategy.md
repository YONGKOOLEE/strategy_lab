# 전략 rsi2-meanrev v1

<!-- 양식: 운영 docs/templates/strategy-template.md (CP-030 반영판). 전략실 연구 후보 — 운영 등록 없음. -->

- 전략 ID / 이름: rsi2-meanrev / RSI(2) 단기 되돌림
- 버전: v1 (규칙·파라미터 변경 시 +1, 이전 검증 결과 승계 없음 — D-011)
- 설명: 종가가 SMA(trend_n) 위인 종목이 RSI(2) < rsi_entry로 급락하면 진입. 종가 > SMA(5), 보유 거래일 ≥ hold_max, 또는 평균 매입가 대비 −stop_pct이면 청산. 빈 슬롯은 RSI 낮은 순으로 채운다.
- 상태(시장별): M1 초안(전략실 연구). 운영 등록 없음
- 대상 시장: M1
- 유니버스 방식: U-A 고정 목록 — 출처: 전략실 `data\daily` 30종목(2026-10-07 시총 상위 30 **사후 선택**)
- 보유 기간: 1~hold_max(5) 거래일 / 최대 보유 제한 = hold_max

## 판정 시점
- 트리거(CAP-TRG-01), 시장 현지 시각: KST 09:30 1일 1회. 전일까지 확정 일봉만 사용.

## 규칙 표 (§2.2)
| 규칙 ID | 종류 | 입력 | 판정 시점 | 조건 | 행동 | 무효 조건 | 우선순위 |
|---|---|---|---|---|---|---|---|
| EXIT-1 | EXIT | CAP-DAT-01·상태 입력 | 09:30 | 보유 AND (종가 > SMA(5) OR 보유 거래일 >= hold_max OR 종가 < 평균 매입가 × (1 − stop_pct)) | 전량 시장가 청산 | 데이터 품질 실패·처리 중 주문 | 1 |
| ENTRY-1 | ENTRY | CAP-DAT-01·상태 입력 | 09:30 | 전략 보유 수 < 3 AND 미보유 AND 종가 > SMA(trend_n) AND RSI(2) < rsi_entry — RSI 낮은 순(동률 종목코드)으로 빈 슬롯 수만큼 | S-3 시장가 진입, 손절가 = 전일 종가 × (1 − stop_pct) | 데이터 품질 실패·거래 상태 이상·처리 중 주문·09:30 기준가 <= 손절가(갭하락) | 1 |

- 09:30 판정 시 스냅샷의 마지막 봉은 **전일** 봉. 모든 조건은 전일 종가 기준, 09:30 시가는 기준가·크기 계산에만 쓴다. 당일 청산으로 비는 슬롯은 다음 판정부터 채운다.

## 파라미터 (R-19)
| 이름 | 타입 | 단위 | 허용 범위 | 설명 |
|---|---|---|---|---|
| trend_n | int | 거래일 | 50~200 | 추세 필터 SMA(초기값 100) |
| rsi_entry | int | RSI | 5~30 | RSI(2) 진입 기준 미만(초기값 10) |
| hold_max | int | 거래일 | 2~15 | 최대 보유(초기값 5) |
| stop_pct | decimal | 비율 | 0.02~0.10 | 손절 비율(초기값 0.05, 종가 판정) |
| risk_ratio | decimal | 비율 | 0.001~0.005 | 1회 위험(초기값 0.004) |
| max_weight | decimal | 비율 | 0.01~0.10 | 종목 비중 상한(초기값 0.09) |
| order_cap | decimal | 원 | 100,000~50,000,000 | 1회 주문 상한(초기값 1,000,000 = 계좌 L7) |
- 상수: TOP_N = 3, RSI 기간 2, 청산 SMA 5. 수치 파라미터 7개 → ±20% 변형 14개(L7 지배 시 risk_ratio·max_weight·order_cap 6개 "결과 동일").

## 신호 유효 기한 (§2.6)
- 판정 기준 시각 + 10분 / 절대 상한 10분

## 미체결 정책 (CAP-ORD-03 선언 시)
- 해당 없음(시장가만) — 시스템 기본

## 포지션 크기 (§2.8)
- S-3: min(기준 금액×risk_ratio ÷ (기준가 − 손절가), 기준 금액×max_weight ÷ 기준가, order_cap ÷ (기준가×1.3)) 내림
