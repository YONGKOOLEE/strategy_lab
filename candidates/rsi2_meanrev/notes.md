## 사전 등록 (v1, 2026-10-11) — 실행 뒤 변경 금지
- 가설: 상승 추세 대형주의 2~3일 급락(RSI(2) < 10)은 수일 내 되돌림이 잦다(단기 반전). 이 데이터에서 실증 없음(ideas/2026-10-11-rsi2-meanrev.md). 비용(왕복 0.43%)이 기대 되돌림과 같은 자릿수라 결과가 비용 가정에 좌우됨을 미리 적음.
- 파라미터 초기값·근거: trend_n 100 / rsi_entry 10 / hold_max 5 / stop_pct 0.05(운영 cand-meanrev-rsi 메모와 같은 값, 데이터 보고 고르지 않음), risk_ratio 0.004·max_weight 0.09·order_cap 100만.
- 폐기 기준: quick(운영 한도, 창 4·7 합산) 거래당 기대값 ≤ 0 **또는** 거래 < 10 → 폐기. validate 미충족·판단 불가 → 폐기 또는 v+1.
- 보조 실행(판정 아님): `research/limits-scale-test-l1fix.toml` + order_cap 1,000만으로 % 기대값 기록(사용자 미결정 한도 가정).
- 시도 상한: v1 **2회**(critic 권고로 실행 전 5→2 축소 — 구조적으로 비용에 지는 전략이라 파라미터 조정으로 살릴 가능성이 낮음). **C-3 미충족이면 v+1 없이 폐기.**
- 선행 결과(사전 기록): 운영 메모 candidates-2026-10-03 — 같은 규칙·값으로 005930 단일 종목 2024-07~2026-10 백테스트 35건, 비용 포함 −0.05%, 승률 51%, "비용 5.6만 원이 수익을 상쇄". 005930은 이번 30종목에 포함된다. 초기값은 그 메모의 값을 그대로 쓴 것이며 데이터로 조정하지 않았다.
- 보조 실행(scaleB) 결과는 **v2 파라미터 선택에 쓰지 않는다**(규모 효과 기록용).
- 결과 읽을 때 "신호 수 / 거부 수 / 거부 사유별"과 청산 사유 분포(SMA5·hold_max·손절)를 함께 기록한다. 폐기 시 "가설이 틀렸는지, 유니버스(대형주 = 유동성 프리미엄 최소)가 맞지 않는지" 구분해 적는다.
- 미리 적는 예상: 거래 수는 많고(C-2 충족 쉬움) 거래당 기대값은 작아 **C-3(슬리피지 2배)에서 미충족** 가능성이 높다. 2022(창 4) 같은 추세 붕괴에서 손절 반복 예상.

- critic(2026-10-11, 실행 전): 차단 0 / 비차단 7(비용 민감 "차단에 가까움", 시도 상한 축소·선행 결과 명시·보조 실행 불사용 권고 → 위 사전 등록에 반영). 숨은 필터: 09:30 시가가 전일 종가×0.95 이하로 갭하락하면 진입 없음(strategy.md 무효 조건에 추가).
