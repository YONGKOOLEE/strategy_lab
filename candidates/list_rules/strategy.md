# 전략 list-rules v2

- 전략 ID / 이름: list-rules / 목록 운용 규칙 세트(즉시 진입·국면 필터·보수/공격 청산)
- 버전: v2 (규칙·파라미터 변경 시 +1 — D-011). v1→v2: ENTRY-1에 '전일 종가 > SMA(sma_n)' 추가(재진입 왕복 결함 수정, notes.md)
- 설명: 사용자가 준 종목(1개 또는 목록) 안에서 KOSPI > SMA(regime_n)일 때 빈 슬롯만큼 20일 평균 거래대금 순으로 즉시 진입. 청산은 보수형(종가 < SMA(sma_n) 또는 hold_max) 또는 공격형(평균 매입가 −stop_pct 또는 hold_max). 증액 없음. **우위는 사용자의 종목 선택이 공급**하고 이 전략은 리스크·실행 규칙이다.
- 상태(시장별): M1 초안(전략실 연구). 운영 등록 없음
- 대상 시장: M1
- 유니버스 방식: **U-B 사람 제출 목록** — 출처: 사용자(모드 1: 종목 1개, 모드 2: 스크리닝 목록). 전략실 시험은 `data/lists/sample10`(기계적 표본). 지수 종목 `KOSPI`는 국면 입력만.
- 보유 기간: 보수형 수일~120거래일 / 공격형 ≤60거래일

## 판정 시점
- 트리거(CAP-TRG-01), KST 09:30 1일 1회. 전일까지 확정 일봉만 사용.

## 규칙 표 (§2.2)
| 규칙 ID | 종류 | 입력 | 판정 시점 | 조건 | 행동 | 무효 조건 | 우선순위 |
|---|---|---|---|---|---|---|---|
| EXIT-1 | EXIT | CAP-DAT-01·상태 입력 | 09:30 | 보유 AND [exit_mode=sma: 전일 종가 < SMA(sma_n) / exit_mode=fixed: 전일 종가 < 평균 매입가 × (1 − stop_pct)] OR 보유 거래일 >= hold_max | 전량 시장가 청산 | 데이터 품질 실패·처리 중 주문 | 1 |
| REENTRY-1 | REENTRY_BLOCK | 상태 입력 | 09:30 | 직전 청산 있음 AND 청산일 뒤 확정 일봉 수 < reentry_wait (0 = 없음) | ENTRY-1 신호 없음 | — | 1 |
| REGIME-1 | REENTRY_BLOCK | CAP-DAT-01(KOSPI) | 09:30 | 지수 전일 종가 <= SMA(regime_n) OR 지수 없음·부족 (0 = 없음) | ENTRY-1 신호 없음(청산·보유 영향 없음) | — | 2 |
| ENTRY-1 | ENTRY | CAP-DAT-01·상태 입력 | 09:30 | 전략 보유 수 < 3 AND 미보유 AND REENTRY-1·REGIME-1 아님 AND 전일 종가 > SMA(sma_n) — 20일 평균 거래대금(종가×거래량) 큰 순(동률 종목코드)으로 빈 슬롯 수만큼 | S-3 시장가 진입, 손절가 = 전일 종가 − atr_mult×ATR14 | 데이터 품질 실패·거래 상태 이상·처리 중 주문·09:30 기준가 <= 손절가 | 1 |
- 증액(INCREASE)·감액(REDUCE) 규칙 없음 — 피라미딩 연구(2026-10-11) 결과 상승 증액 9/9년 열위.
- 당일 청산으로 비는 슬롯은 다음 판정부터 채운다. 모드 1(종목 1개)에서는 슬롯 1개만 쓰이고 나머지는 비어 있다.

## 파라미터 (R-19)
| 이름 | 타입 | 단위 | 허용 범위 | 설명 |
|---|---|---|---|---|
| exit_mode | str | — | sma / fixed | 보수형 / 공격형(초기값 sma) |
| sma_n | int | 거래일 | 5~60 | 진입 필터(종가 > SMA, 두 모드 공통) + 보수형 청산 기준(초기값 20) |
| stop_pct | decimal | 비율 | 0.03~0.20 | 공격형 손절(초기값 0.07 — T2에서 좁다고 확인, v2 재검토) |
| hold_max | int | 거래일 | 10~250 | 최대 보유(보수 120 / 공격 60) |
| reentry_wait | int | 거래일 | 0~40 | 재진입 대기(초기값 0) |
| regime_n | int | 거래일 | 0~250 | 국면 필터(초기값 200, 0 = 없음) |
| atr_mult | decimal | 배 | 1~5 | 크기 계산 손절 거리(초기값 2) |
| risk_ratio / max_weight / order_cap | decimal | — | 0.001~0.005 / 0.01~0.10 / 100,000~1,000,000 | 계좌 한도 이하 공통값 |

## 신호 유효 기한 (§2.6)
- 판정 기준 시각 + 10분 / 절대 상한 10분

## 포지션 크기 (§2.8)
- S-3: min(기준 금액×risk_ratio ÷ (기준가 − 손절가), 기준 금액×max_weight ÷ 기준가, order_cap ÷ (기준가×1.3))
