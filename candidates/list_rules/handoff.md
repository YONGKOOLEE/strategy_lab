# 인계 패킷(초안) — list-rules v3 (2026-10-12, **운영 P-6 대기**)

전략실 결과는 연구 참고다. 공식 판정·등록·PAPER·LIVE는 운영 저장소 절차와 사용자 승인(A-ID)으로만.
**이 전략은 우위를 주장하지 않는다** — 모드 1·2(사용자 지정 종목/목록)용 진입·청산·리스크 규칙 세트다. 우위는 사용자의 종목 선택이 공급한다.

## 상태: 운영 전제 미충족(P-6) → 인계 보류
- 차단 전제: **U-B 목록 입력 인터페이스(P-6)** — 목록 파일 형식·갱신 시각·버전 기록·목록 변경 시 보유 처리·등재일 상태(눌림 혼합 진입용, 선택). 전략은 목록 멤버십을 검사하지 않으므로 운영이 스냅샷 종목을 목록으로 제한해야 한다. P-6 없이 등록하면 알고 있는 전 종목을 거래한다.
- 비차단 전제: KOSPI 지수를 스냅샷 종목 `KOSPI`로 넣는 방식(운영 데이터 경로 결정), U-B 전략의 판정 방식(C-2~C-4 적용 불가 → 동작 검증 + PAPER 기준).

## 전략실 검증 기록
- 구조 검사 통과(v1~v3). critic v1→v2 차단 2건 반영(U-B 멤버십·시각 정정), 비차단 반영.
- quick(sample10, 창 4·7): 2022 거래 0(국면 차단), 동시 보유 ≤ 3, 거부 ≤ 2. 보수형 왕복 50·보유 중앙 5일(v1 113·1일의 재진입 왕복 결함 수정) / 장기형 왕복 9·보유 중앙 14일, EXIT-1/EXIT-2 분리 기록. 기대값은 임의 목록이라 판정에 쓰지 않음.
- 규칙 재료 연구(200종목 대리 표본): 즉시 진입 기본(눌림 혼합은 등재일 상태 필요) / 청산 규칙은 공정 기준선 대비 초과 ≈ 0(보유 기간 선택) — 보수형 SMA20 최악 10% −8.5%, 장기형 FIX12/120 상위 10% +70.8%·피격률 54% / 상승 피라미딩 9/9년 열위 → 없음 / 국면 필터 효과 확인(rs-momentum 대조 실험).
- 시도 장부 `trials.jsonl` 6회(v1 2·v2 2·v3 2).

## 한계 · 미확인
생존편향(규칙 간 차이에는 영향 작음), 규칙값은 전 종목 대리 표본에서 고정 — 사용자 실제 목록 분포에서 다를 수 있음 → PAPER에서 재측정. −12% 손절도 코스피200 개별 종목 120일 안에 절반 피격. 하락 국면 **중간에** 보유 중 청산되는 상황은 전략실에서 미시험(창 시작이 빈 포지션).
